<details>
  <summary><h2>What those projects are</h2></summary>
  <br/>

**[ZenFit](https://github.com/2deva/ZenFit)** is a voice fitness coach on Gemini Live. It notices a broken streak, offers a short restart instead of a full workout, and talks you through it. Sessions are traced so the agent is judged on whether someone actually comes back.

**[MarketAI](https://github.com/2deva/MarketAI)** turns a short brief into a marketing image. Flask and Tailwind in front of DALL·E, with a style, a size, and a download.

**[Phishy](https://github.com/2deva/Phishy)** is a machine-learning check for phishing sites.

**[Line-Follower](https://github.com/2deva/Line-Follower)** is a Raspberry Pi car that follows a line, driven from a Python and Flask remote.

**[Delivery drone](https://github.com/2deva/Capstone-Project-Delivery-Drone-)** is a low-cost drone built to carry a light package a short distance and release it on a marked drop zone.
